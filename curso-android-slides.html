Dia 1 — Montando a tela06
dia 1 · linguagem

Kotlin, em um slide

A linguagem do Android hoje. Você não precisa dominar — só reconhecer o básico pra acompanhar.

  • val não muda · var muda
  • fun declara uma função
  • String? pode ser nulo · ?: dá um valor padrão
  • $nome insere um valor dentro do texto
exemplo
val nome = "Harry"        // texto, não muda
var pontos = 0           // número, pode mudar

fun saudacao(n: String) = "Olá, $n"

val casa: String? = null
println(casa ?: "Sem casa ainda")

Jetpack Compose: UI declarativa

o jeito antigo

Você monta a tela em arquivos separados e atualiza cada pedaço na mão quando algo muda. Fácil esquecer um caso.

com o compose

Você descreve como a tela deve ser para um estado. Mudou o estado, o Compose redesenha o que for preciso.

tela = f( estado )
Dia 1 — Montando a tela08
dia 1 · blocos de UI

A função @Composable

No Compose, a tela é feita de funções. Uma função @Composable desenha um pedaço da interface — e pode usar outras dentro dela.

Text — texto Column — empilha Row — lado a lado Box — sobrepõe Button — botão Image — imagem Spacer — espaço
exemplo
@Composable
fun Saudacao() {
    Column {
        Text("Bem-vindo a Hogwarts")
        Button(onClick = { }) {
            Text("Começar")
        }
    }
}
Dia 1 — Montando a tela09
dia 1 · ajuste fino

Modifier

Todo bloco aceita um Modifier: tamanho, espaçamento, cor de fundo, borda, clique. É encadeado — e a ordem importa.

exemplo
Text(
    "Grifinória",
    modifier = Modifier
        .fillMaxWidth()          // ocupa a largura
        .background(Color.Red)   // pinta o fundo
        .padding(16.dp)         // respiro por dentro
)

Trocar a ordem de background e padding muda o resultado na tela.

dia 2 · o coração do compose

Estado & recomposição

Estado é a informação que muda enquanto o app roda: a rodada atual, o placar, o personagem da vez.

  • remember { mutableStateOf(...) } guarda o valor entre redesenhos.
  • Mudou o estado → o Compose recompõe só o que usa aquele valor.
exemplo
var cliques by remember {
    mutableStateOf(0)
}

Button(onClick = { cliques++ }) {
    Text("Cliques: $cliques")
}

Dia 2 — Dando vida à tela15
dia 2 · dados

Buscar dados da internet

O personagem de cada rodada vem de uma API pública — um endereço na web que devolve dados.

API REST

A fonte

Um endereço que responde com os dados do personagem em formato JSON (texto estruturado).

Retrofit + Gson

A ponte

Fazem a chamada e transformam o JSON num objeto Kotlin que a tela consegue usar.

Coil

A imagem

Baixa e mostra a foto do personagem a partir do link, com cache.

Isso demora um tico → roda em segundo plano pra não travar a tela.
